# Expected — Settings

## Pass

- Sub-nav is `surface-3` `#18191a`; the active item is `surface-2` + `ink`
  (surface lift, not color).
- Inputs use `surface-1` bg, 8px radius, 8×12 padding, `hairline` border.
- Input focus is a 2px `primary-focus` `#5e69d1` ring at 50%.
- Section titles are `card-title` (22/500); helper text is `caption`
  `ink-subtle`.
- Save button is `primary`; Cancel is `secondary`.
- Danger zone is a bordered panel with a tertiary/secondary action — no red
  fill.

## Fail

- A colored (lavender or red) sidebar background.
- A pill-shaped button or input.
- Lavender used as a background fill anywhere.
- Danger zone rendered as a red button/fill.
